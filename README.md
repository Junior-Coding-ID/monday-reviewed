## What it does

`main.ts` writes one line — a one-star review of the author's own Monday — to `<output-dir>/entry.txt`, verbatim:

> My Monday gets one star: I stepped off the train to let a guy out, and the doors took his side.

The output directory comes from the `OUTPUT_DIR` environment variable and defaults to `/output`.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is).
